# Gym Management System

A Python-based gym management system for the CPE/EE 551 course project.

## Project Overview

This project aims to help gym owners manage daily operations and make gym services more convenient for members. It brings membership information, attendance records, and fitness class reservations together in one program.

Administrators will manage member records, membership renewals, and fitness classes. Members will be able to view their own membership status, check how many members are currently inside the gym, and reserve available classes.

## Planned Features

- Member Management: Add, search, and update member records.
- Membership Tracking: Check membership status, expiration dates, and renewals.
- Attendance Tracking: Record check-ins and check-outs and calculate current gym occupancy.
- Class Reservations: View classes, book or cancel reservations, and prevent duplicate bookings and overbooking.
- Reports: Display summaries and charts of membership status, attendance, and class enrollment.
- Data Storage: Read and save records using CSV files.

## Planned Technologies

- Python 3.12, 3.13, or 3.14
- Jupyter Notebook (`main.ipynb`) and supporting Python modules
- Pandas for data processing
- Matplotlib for charts
- Pytest for testing

## Data

The project will use fictional member records and sample class schedules created by our group. Current gym occupancy will be calculated from recorded check-ins and check-outs.
